# GeoScope publication manuscript (revised figures)

Build: `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex`. Supplementary PDF: `latexmk -pdf -interaction=nonstopmode -halt-on-error supplementary.tex`. Run `biber main` and `biber supplementary` if citations need manual regeneration.

The 7 main and 11 supplementary figures are generated by the separate `publication_figures.zip` archive. The original manuscript results are preserved, except outdated images are replaced and moved to supplementary plots where appropriate. Supporting information remains a separate manuscript with its own figure numbering. Frozen numerical research data remain unchanged.
