# GeoScope — canonical unified manuscript

The active main manuscript is **one study** of physically licensed atomistic evidence, tested with an original 55-system UMA collection and complementary 48-system external OC20 collection. The two data collections remain separate in Methods and numerical tables because their output-policy comparisons differ.

## Primary source files

- `main.tex` includes the revised Abstract, Introduction, Methods, a single `sections/results_discussion.tex` with six scientific-question-driven subsections, Conclusion, and submission declarations.
- `supplementary.tex` contains source-specific and cross-collection methods/diagnostics.
- `figures/figure_01.pdf` is a new shared-framework overview, regenerated by `python figures/make_figure_01.py` (requires `reportlab`).
- `figures/figure_02.pdf` through `figure_07.pdf` and `figure_S01.pdf` through `figure_S11.pdf` retain the original archived data-derived plots.
- `references.bib` has duplicate citation keys removed and some publication details corrected; it should still undergo final journal-specific review.
- `archive/unused_sections/` contains inactive legacy narrative content for editorial provenance. Other historical `sections/*.tex` may remain tracked in the old repository and are not included by `main.tex`.

## Compile

From this folder, with `latexmk`, `biber` and LaTeX installed:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
latexmk -pdf -interaction=nonstopmode -halt-on-error supplementary.tex
```

## Data and claims

This manuscript restructuring preserved previously reported counts, not fresh model inference. Its shared-framework Figure 1 is new editorial artwork. The original 55-system check ablation was **not** replicated as a matched experiment on the external 48-source collection. Strict JSON, outer-fence-normalized scoring and oracle operation repair are distinct analysis regimes; the deterministic oracle is a valid benchmark-only baseline, not a deployable hybrid model. Independent expert chemical review remains pending. Authorship differs between the two inherited source documents and requires confirmation before submission.
