\section*{Data and code availability}
The reproducibility code and the frozen original 55-system first-attempt archive are currently hosted at \url{https://github.com/oissakah/geoscope-atomistic-evidence}, which was private at the time of this review. The original 55-system case-level CSVs can be regenerated from that frozen archive. The external OC20 raw-model-response and token-span archives, large trajectory files, and some parent computational archives are not yet included in the repository. Public archival release and access details must be confirmed before publication.
