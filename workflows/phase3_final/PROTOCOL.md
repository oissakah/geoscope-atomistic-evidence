# Frozen final evaluation protocol

Version `final_scope_bounds_v1`, 20 October 2026. Updated using development evidence before any final language-model output. New-system geometry was inspected for the declared physical quality criteria; no model predictions were used to select sources or tune this protocol. This is a prospective frozen model evaluation, not an externally preregistered study.

1. **Cohort.** Pin the reviewed source ZIP SHA256 `5e9d6067e2855255a52f03bb8ae94509a79ae7af03ae4b43a93114ed5ec34bf7` and development ZIP SHA256 `8e8e77cc36b6f1dde2ab282bfb4f79f5c00d9f5333eff0fc0d9e593781727b86`. Use exactly the 55 accepted source groups and their controls in `data/qualification_gate.json`; retain the five exclusions and original 60-source denominator in provenance. The 20 development groups are disjoint. No replacements, new relaxations or outcome-driven exclusions.
2. **Quantities.** M is equal-weight mobile-atom RMSD, A is adsorbate RMSD in the same stored frame, both with identical independently minimum-imaged per-atom displacements. The adsorbate set is a strict subset of mobile atoms. I is internal adsorbate RMSD after connected-graph unwrapping and proper Kabsch alignment without reflection. Atom correspondence is fixed; selected sets, periodic flags and all record definitions are supplied.
3. **Permitted relations.** With nA adsorbate and nM mobile atoms, write the complement as S. The exact residual identity is nM*M^2 = nA*A^2 + sum(residual_norm^2 over S). Therefore M >= A*sqrt(nA/nM), and 0 <= A <= M*sqrt(nM/nA). A missing mobile value with only A supplied permits [A*sqrt(nA/nM), infinity); a missing A with only M supplied permits [0, M*sqrt(nM/nA)]. No coordinates or numeric cell vectors are supplied, and no additional constraints are assumed. Fixed anchors constrain neither unknown internal shape nor mobile motion. I <= A is not generally valid under independently minimum-imaged frame residuals; no such bound is licensed.
4. **Cases.** Six direct cases per source compare the three quantities at 0.75 and 1.25 of the measured value, with a fixed hashed operator and rotated unit-conversion family. Four missing-M cases use 0.75 or 1.25 of its lower bound with both at-most/at-least comparisons. Four missing-A cases analogously use its upper bound. One internal-missing/anchor-only case and one wrong-pair case are insufficient. Both presentations retain equivalent numerical facts, with fresh neutral eight-hex evidence/pair aliases; report rows omit semantic quantity IDs. A direct metric at or below 1e-8 would be skipped with an explicit audit rather than replaced. All 55 qualified sources pass the fixed applicability conditions; no cases are skipped. Total: 1,760 variants, 550 supported, 550 contradicted, 660 insufficient.
5. **Proofs.** Operations are `value`, `mobile_lower`, `adsorbate_upper`, `none`. Enumerate every licensed single-record conclusive proof from the public payload. A decisive label requires one evidence ID and its correct operation; any valid alternative proof is accepted. Insufficiency means no supplied licensed value or bound settles the inequality and requires empty IDs/`none` for direct answers. A range entirely satisfying the inclusive inequality supports it; a range entirely violating it contradicts it; a straddling range is unresolved. Decimal interval calculations use the declared bound directions, not scalar substitution.
6. **Requests.** Direct answers contain exactly `verdict`, `evidence_ids`, `operation`. Selectors contain exactly `evidence_ids`, `operation`, without a verdict. Empty selection requires `none`; a selected record requires exactly one copied ID and one non-none operation. Each request is independent, and only `model_payload` is sent. Generic mathematical relations are supplied to every model; this is not a test of memorized RMSD theorems. There are 10,560 requests: three fixed models × two conditions × 1,760 variants.
7. **Inference.** Reuse the exact successful cached Qwen3-4B-Instruct-2507, Phi-4-mini-instruct and SmolLM3-3B manifests. Python 3.12, Transformers 5.3.0, PyTorch 2.13.0 CUDA 12.6, Accelerate 1.12.0, NumPy 2.3.5. Greedy BF16/SDPA, batch 2, at most 160 new tokens, at most 6,144 input tokens; no input truncation. SmolLM extended thinking is disabled and its template date frozen. Record checkpoint hashes, hardware/software, full prompt hash, unpadded input-token-ID hash, raw output and request identity. No answer repair or automatic regeneration of failed requests.
8. **Parsing.** Accept one strict JSON object, optionally inside exactly one entire enclosing lower-case `json` or unlabelled Markdown fence. A closing fence may follow the JSON inline; only wrappers/whitespace are removed. Reject commentary, nested/multiple fences, extra keys, duplicate keys/IDs, invalid enums, wrong types or citation/operation-contract violations. No ID correction, case folding, coercion or content extraction. This rule is fixed before final inference; previous run scores are unchanged.
9. **Controls.** The same selector output feeds arithmetic-only, run-only and full-definition validation. Arithmetic applies the chosen operation without scope/pair validation; run-only checks pair identity; full validation also checks physical-definition and operation compatibility. All use the same interval comparison and unit conversion. Unknown IDs are invalid. No selection, invalid scope or an unresolved bound produces a separate rejection action. No branch searches for another proof. The deterministic public-payload oracle is reported separately and is a strong exact solver for this controlled family.
10. **Primary outcomes.** For Qwen, compare full-definition with run-only validation on identical raw selections: bad numerical acceptances prevented and answerable numerical coverage lost, with correct accepted verdict-plus-proof rate on answerable cases. Report acceptance on truly insufficient cases, conditional accepted correctness, exact operation/evidence validity and missing/invalid/rejected fractions. Keep these as a tradeoff rather than a single inflated global score. Phi/SmolLM, arithmetic/direct comparisons, subgroup and pair-consistency results are secondary/exploratory.
11. **Insufficiency versus rejection.** Direct/oracle three-way scientific accuracy may credit a correct insufficiency verdict. Selector pipeline rejection never receives that credit; it indicates an unverified selected proof. A rejected answerable packet is a coverage loss. Zero unsafe acceptance under exact full validation is a property of the declared rules, not evidence of learned scientific reasoning. Report correct accepted decisions and coverage beside safety counts.
12. **Statistics and completeness.** Include every expected case for all three models; failed, missing, truncated, duplicate, malformed and invalid-ID responses remain errors or nonanswers as appropriate. Report structured/prose and case-family results separately. Resample whole source-system groups 1,000 times with seed 20261021, retaining all correlated thresholds/presentations. Paired method effects share the same selections. Intervals are descriptive percentile intervals, not multiplicity-adjusted confirmatory significance tests. Preserve complete threshold/representation pair scores as diagnostics.
13. **Freeze and stop rule.** Preparation hashes source, protocol, public/gold cases, configuration, cohort gate and model manifests before GPU evaluation. Any mismatch blocks inference. Collect all first-attempt outputs including partial failures and return the ZIP. Do not revise this protocol or select a favorable repeat after viewing final outcomes. Analyze the fixed result honestly, including a null finding, narrow same-domain generalization, uneven chemical attrition and the perfect deterministic baseline.
